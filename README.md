## What's here

### AI for Managers: Coaching, Planning & Decision Support
A role-based course (7 modules, 31 lessons, 7 scenario-based knowledge checks) that teaches people managers to use AI in their real workflow without over-relying on it. It demonstrates:

- behaviour-first objectives mapped to Bloom's action verbs
- a foundations-to-advanced learning path
- scenario-based assessment (decision trees, error-spotting audits, applied quizzes) instead of recall
- automation bias built in as a through-line, not a footnote

Each lesson is a self-contained, interactive HTML page (no build step, no dependencies).
